# Никита Филиппов — Portfolio

Personal portfolio website built with Next.js 16, TypeScript, Tailwind CSS, and GSAP animations.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** GSAP, Framer Motion
- **Components:** Custom CardSwap (react-bits inspired), Lucide Icons
- **Font:** Geist (Sans + Mono)

## Features

- Cinematic dark corporate theme
- Typing animation on hero section
- Scroll-triggered section animations
- CardSwap component for project showcase (from react-bits)
- Responsive design (mobile-first)
- SEO optimized

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build

```bash
npm run build
npm start
```

## Deploy

Deploy on Vercel, Netlify, or any Node.js hosting.
